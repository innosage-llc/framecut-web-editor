# Web release 0.4.1

The Pro paywall uses a larger carousel with all five counter-free Mac App Store artworks,
six-second automatic rotation, and compact plan-specific coverage. Shared Pro features stay
beside the artwork. Manual navigation, hover/focus pausing, hidden-page pausing, and reduced
motion are supported.

The production build gate, TypeScript, and 13 browser integration tests passed. Deployment
results will be recorded after publication.
